Lección 01

Variables y Tipos de Datos

Las variables son contenedores donde almacenamos datos que la aplicación necesita para funcionar. En JavaScript moderno utilizamos principalmente let para variables cuyos valores van a cambiar, y const para valores fijos o constantes.

Los tipos de datos primitivos más comunes son:

  • String: Cadenas de texto declaradas entre comillas.
  • Number: Números enteros o decimales.
  • Boolean: Valores lógicos (true o false).
// Declaración de variables en JavaScript
const usuario = "Maria";
let saldo = 150000;
let cuentaActiva = true;

saldo = saldo + 50000; // El saldo cambia a 200000
Lección 02

Estructuras Condicionales

Las estructuras condicionales (if, else if, else) permiten a tu programa tomar decisiones automáticas evaluando si una condición lógica resulta verdadera o falsa.

Son fundamentales para la validación de formularios, el control de acceso a módulos y la gestión de permisos en sistemas web. 

// Estructura de decisión simple
let edad = 18;

if (edad >= 18) {
    console.log("Acceso concedido al sistema.");
} else {
    console.log("Acceso restringido: Debes ser mayor de edad.");
}
Lección 03

Bucles y Ciclos (Loops)

Los ciclos o bucles permiten ejecutar un bloque de código múltiples veces de forma automática sin necesidad de duplicar instrucciones. El ciclo for es la estructura de repetición más común en JavaScript.

Se utiliza habitualmente para recorrer listas de datos (arreglos) como registros contables, listas de usuarios o inventarios. 

// Ejemplo de ciclo for recorriendo un arreglo
const productos = ["Factura", "Recibo", "Cotización"];

for (let i = 0; i < productos.length; i++) {
    console.log("Procesando documento: " + productos[i]);
}
Lección 04

Funciones y Modularidad

Una función es un bloque de código reutilizable diseñado para realizar una tarea específica. Recibe entradas opcionales llamadas parámetros y puede retornar un resultado.

Organizar el código en funciones facilita el mantenimiento, evita la duplicación y mejora sustancialmente la legibilidad de la arquitectura del software. 

// Función para calcular impuesto IVA en un ERP
function calcularTotalConIVA(subtotal) {
    const porcentajeIVA = 0.19;
    const total = subtotal + (subtotal * porcentajeIVA);
    return total;
}

let pagoFinal = calcularTotalConIVA(100000); // Retorna 119000
console.log("Monto total a facturar: $" + pagoFinal);
